Diagnostics

Each dart you correct is saved with the cameras' pictures, the detector's view and the true position in debug/ beside the configuration (/data/ochecore/debug in Docker), about 1 MB each.

Accuracy

Every dart the cameras report counts: right unless you correct it to another score, or uncertain (?). Demo darts do not count. A full configuration reset also clears it.
